📦 CONTENU DE CE DOSSIER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Ce dossier contient les fichiers statiques générés par Next.js pour
le site Séjoura. Tous les fichiers doivent être uploadés à la racine
du dossier homiqio.com sur le serveur o2switch.

🔧 FICHIERS IMPORTANTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

.htaccess           → Configuration Apache (OBLIGATOIRE)
index.html          → Page d'accueil
404.html            → Page d'erreur 404
_next/              → Fichiers JavaScript et CSS de Next.js
assets/             → Images et ressources
favicon.ico         → Icône du site
logo.png            → Logo Séjoura
*.html              → Pages du site

⚠️  IMPORTANT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Le fichier .htaccess DOIT être présent à la racine
2. Tous les fichiers doivent être uploadés (y compris les dossiers cachés)
3. Les permissions doivent être: 755 pour les dossiers, 644 pour les fichiers
4. Ne modifiez AUCUN fichier manuellement sur le serveur

✅ VÉRIFICATION POST-DÉPLOIEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Après le déploiement, vérifiez:
□ https://homiqio.com s'affiche correctement
□ La navigation entre les pages fonctionne
□ Les images se chargent
□ Le HTTPS est actif
□ Les routes dynamiques fonctionnent (/property/1, /service/1, etc.)
